# ios-one-command 0.1.0-preview.1

From an iOS project to a running app, with one command.

## Download / ダウンロード

Download **IOS_One_Command_Start.command** from this release's Assets, then run on your Mac:

```bash
bash "$HOME/Downloads/IOS_One_Command_Start.command"
```

必要なもの：対応するMacとフル版Xcode、Python 3.9以降、準備済みのiPhone/iPad。
この1ファイルにソースを同梱しています。`~/Dev/ios-one-command`に準備し、
サンプルのビルド・インストール・起動まで案内します。

The standalone launcher includes the source ZIP. Full Xcode 15+ and Python 3.9+
must already be installed; Xcode must support the connected device's OS.
Apple Account sign-in, trust and Developer Mode require your own first-use setup.

- **IOS_One_Command_Start.command**: self-contained Mac launcher.
- **ios-one-command-0.1.0-preview.1.zip**: reviewed source distribution.
- **SHA256SUMS**: SHA-256 checksums for these two downloads.

If you download all three files into one folder, verify them there with
`shasum -a 256 -c SHA256SUMS`. These hashes detect mismatched downloads;
they are not a developer signature or notarization.

## Verified scope / 確認済みの範囲

- User-reported iPhone run: Xcode 26.2 (17C52), iOS 26.6.1 (23G83),
  HelloDevice build/install/launch, visible screen and confirmation-button interaction.
- Initial GitHub CI: Python 3.9/3.13 on Linux and Python 3.11 on macOS passed;
  Xcode 26.6 (17F113) built, installed and launched HelloDevice on an iPhone 17
  Simulator running iOS 26.5. This was a launch smoke test, not a UI interaction test.
- Release publication requires the Python, Simulator and Git-history secret-scan jobs to pass.

See [the validation record](https://github.com/masaakisakamoto/ios-one-command/blob/v0.1.0-preview.1/docs/validation.md)
for the evidence and remaining checks. A second developer's Mac, physical iPad
and existing third-party projects remain unverified. This is an early preview.

The standalone installer stops if `~/Dev/ios-one-command` already contains a
different version or edited files. Existing users can extract the source ZIP to
a separate folder and run `bash Try_Demo.command` there. This preview does not
automatically merge or upgrade an existing installation.

不具合報告には、端末名やパスを除外した `shareable-report.json` を使ってください。
生のXcodeログや認証情報を貼り付ける必要はありません。
